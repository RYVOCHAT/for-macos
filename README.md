# RYVOCHAT für macOS

Die Desktop-App von [RYVOCHAT](https://ryvochat.com) für den Mac.

**Download:** [ryvochat.com/downloads](https://ryvochat.com/downloads) oder unter [Releases](https://github.com/RYVOCHAT/for-macos/releases/latest).

- `RYVOCHAT.dmg` läuft auf Apple Silicon (M1 und neuer) und auf Intel-Macs
- Läuft ab macOS 12

Beim ersten Start einmal unter Systemeinstellungen → Datenschutz & Sicherheit auf „Trotzdem öffnen“ klicken.
